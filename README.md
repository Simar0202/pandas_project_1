# Sales Data Analysis Using Python

## Project Overview

This project focuses on analyzing sales data using Python to uncover customer purchasing behavior, product performance, and sales trends. The analysis includes data cleaning, exploratory data analysis (EDA), and visualization techniques to generate actionable business insights.

The project was performed using Python libraries such as Pandas, Matplotlib, and Seaborn.

---

## Objectives

* Clean and preprocess raw sales data.
* Perform exploratory data analysis (EDA).
* Identify customer demographics contributing to sales.
* Analyze sales performance across different states.
* Evaluate product and category performance.
* Generate business insights through visualizations.

---

## Tools & Technologies

* Pandas

* Seaborn
* Jupyter Notebook

## Data Cleaning & Preprocessing

The following data preparation steps were performed:

* Removed unnecessary columns.
